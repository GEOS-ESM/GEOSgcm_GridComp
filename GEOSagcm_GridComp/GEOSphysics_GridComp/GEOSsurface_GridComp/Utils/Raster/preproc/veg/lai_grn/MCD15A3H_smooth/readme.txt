## 1. Description
This package provides a parallelized, end-to-end workflow to process 
global MODIS LAI data (MCD15A3H) from 2003-01-01 to 2025-12-31. 
The pipeline applies Quality Control (QC) filtering, temporal interpolation, 
and Savitzky-Golay (TIMESAT-style) smoothing (Jönsson and Eklundh 2004). 

It processes data into localized 2.5x2.5 degree chunks, stitches them into 
standard 10x10 degree MODIS tiles with ubyte + zlib compression, 
upscales the spatiotemporal resolution (15 arc-sec to 30 arc-sec, 
4-day to 8-day), and finally generates a 23-year climatological mean (Climatology). 
This workflow is optimized for the Discover supercomputer to prepare the 
TS LAI for GEOS land surface model ingestion.

Reference:
Jönsson, P., & Eklundh, L. (2004). TIMESAT—a program for analyzing 
time-series of satellite sensor data. Computers & geosciences, 30(8), 833-845.

## 2. File Manifest
This package contains the following primary scripts:

- process_tile_array.py
  The core Python processing script. It handles the I/O, QC filtering, and 
  smoothing for a specific 2.5x2.5 degree sub-tile. 

- stitch_tiles.py
  The post-processing Python script. It loads the 16 corresponding 2.5-degree 
  sub-tiles, merges them into a unified 10x10 degree master tile, applies level-1 
  zlib compression, and writes the final NetCDF product to the `output/` directory.

- submit_global_array.sh
  The master Slurm array bash script that orchestrates the initial workflow 
  across 20 compute nodes.

- prepare_upscale_dirs.sh
  A utility bash script that generates the year-specific subdirectories and 
  populates them with the necessary structural templates.

- upscale_global_array.py
  The spatiotemporal upscaling script. It interpolates the stitched LAI data 
  from a 4-day to an 8-day temporal interval, and aggregates the spatial 
  resolution from 15 arc-sec to 30 arc-sec.

- submit_upscale_global_array.sh
  The Slurm submission script for the upscaling process. It leverages 36 nodes 
  with 18 cores per node for massive parallelization.

- calc_lai_clim.py
  The climatology calculation script. It uses Python multiprocessing to read 
  all upscaled yearly data (2003-2025), computes the multi-year mean and outputs 
  the final dataset into the climatology directory.

## 3. Directory Structure Prerequisites
Before executing the pipeline, the following directory structure must be 
initialized in your working directory to handle logs and I/O routing properly:

- `logs/`            : Stores the Slurm output and error logs (.out/.err).
- `temporary/`       : Stores the uncompressed 2.5x2.5 degree intermediate sub-tiles.
- `output/`          : Stores the highly compressed 10x10 degree merged tiles.
- `template/`        : MUST contain the baseline NetCDF template files.
- `upscaled/`        : Base directory for the year-specific upscaled outputs.
- `MODIS_8-DayClim/` : The final directory generated by `calc_lai_clim.py` where 
                       the 2003-2025 climatological mean tiles are saved.

## 4. Usage Instructions
Due to the Slurm QOS max submission limits (QOSMaxSubmitJobPerUserLimit) on 
Discover, the 648 global grid tasks for the initial processing must be submitted 
in two separate batches.

Please run the workflow by executing the following commands sequentially:

# Step 1: Source g5_modules and create the required base directories
source g5_modules.sh
mkdir -p logs temporary output upscaled

# Step 2: Submit the first batch for initial processing (Tasks 0 to 347)
sbatch --array=0-347%20 submit_global_array.sh

# Step 3: Wait for the first batch to complete (monitor via squeue)
# When all jobs from the first batch are done, submit the second batch:
sbatch --array=348-647%20 submit_global_array.sh

# Step 4: Prepare the directory structure and templates for upscaling
chmod +x prepare_upscale_dirs.sh
./prepare_upscale_dirs.sh

# Step 5: Execute the upscaling script after templates are copied
# This job utilizes 36 nodes to process all 648 tiles simultaneously.
sbatch submit_upscale_global_array.sh

# Step 6: Generate the multi-year climatological mean (2003-2025)
# This script uses native multiprocessing. It is recommended to run this 
# interactively on a compute node (e.g., using salloc) or submit it as a 
# standard Slurm job.
python3 calc_lai_clim.py
